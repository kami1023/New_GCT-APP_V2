## 2025-07-25 - [Search Bar Keyboard Shortcuts and State Scoping]
**Learning:** Adding a global keydown handler for '/' to quickly focus the dashboard search bar significantly improves power-user navigation efficiency. However, the listener must strictly check the current active element's tag name (avoiding focus hijacking when the user is typing inside other text input controls like description or code editors). Moreover, adding a visual indicator for keyboard shortcuts (`<kbd>/</kbd>`) only when the input is empty and unfocused acts as an intuitive, unobtrusive visual cue that guides discovery without cluttering the UI.
**Action:** When implementing global dashboard shortcuts, always verify that `document.activeElement` is not an input, textarea, or content-editable container, and use conditional state to show/hide the shortcut visual badges to prevent layout shifts.
