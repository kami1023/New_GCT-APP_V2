## 2025-02-21 - [Hover-revealed interactive elements focus-visible styling]
**Learning:** Actions revealed only on hover (e.g., 'Delete' buttons in cards) must also be made visible on focus (e.g., using Tailwind's `focus-visible:opacity-100` or `group-focus-within:opacity-100`) and include a clear focus ring to ensure discoverability for keyboard users.
**Action:** Always add keyboard accessibility, visible focus states, and aria-labels to hidden or revealed-on-hover interaction points.
