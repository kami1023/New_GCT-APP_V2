
## 2025-05-22 - [Declarative Search Refactor]
**Learning:** Imperative DOM manipulation for filtering in React (e.g., querySelector and style.display = 'none') is fragile and prevents clean implementation of "No results" states or "Clear Search" functionality.
**Action:** Always refactor legacy imperative UI logic to declarative React state before adding interactive UX enhancements to ensure consistency and easier verification.
