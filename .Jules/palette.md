## 2025-05-15 - [Enhanced Search UX & Declarative State]
**Learning:** Transitioning imperative DOM-based search (direct querySelector) to declarative React state with `useMemo` significantly improved robustness and enabled advanced features like empty states, clear-actions, and programmatic focus management while staying within the 50-line Palette limit.
**Action:** Always favor declarative state for filtering logic in this design system to enable richer UX feedback loops and easier accessibility integration.
