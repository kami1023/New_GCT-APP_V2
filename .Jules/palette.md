## 2025-03-05 - Declarative Search UX, Keyboard Loops & Flicker Prevention
**Learning:** Transitioning imperative, DOM-manipulating search logic to declarative React state enables clean empty states, robust keyboard navigation, and custom focus loops without polluting the DOM. Using refs for programmatic focus on 'Clear' actions and listeners for global keyboard hotkeys ('/') significantly improves power-user workflows, while verifying the non-emptiness of underlying data sets prevents jarring 'No Results' flicker during initial loads.
**Action:** Always prefer declarative state over imperative query selectors for search-and-filter logic; implement a '/' focus listener with activeElement checks, design custom empty states with clear-actions, and preserve item wrapper structures when refactoring.
